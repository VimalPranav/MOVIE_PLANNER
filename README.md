# 🎬 Movie Planner

Movie Planner is a full-stack MERN application that allows users to discover, review, and organize movies. Users can create accounts, browse movies, manage favourites and watchlists, and leave reviews. Administrators can manage the movie database through a secure dashboard.

## 🛠 Tech Stack

### Frontend
- React.js
- Redux Toolkit
- RTK Query
- React Router DOM
- Tailwind CSS
- Vite

### Backend
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- JWT Authentication
- bcrypt.js
- Cookie Parser
- Multer

### Deployment
- Frontend: Netlify
- Backend: Render
- Database: MongoDB Atlas
